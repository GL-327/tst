# Curse art preview

Forty original curses extend the project's ink/bone box-model style. The twenty added
variants reuse a base rig/mechanic with new palettes, crest silhouettes, statistics,
spawn weights and combat move combinations. They are not forty independent AI designs.
Each has a model, animation set, texture, core/wear masks, wounded/critical variants,
LOD model and codex entry. Special Grade texture atlases are at least 256 pixels wide.

Reproduce using tools/expand_content.py then tools/finish_data.py with Python and Pillow.
Use Gradle runDatagen for item models, language and loot. Assets are original procedural
work; no official franchise artwork has been downloaded or embedded.

Animation aliases add run/windup/stagger states. Bespoke animation polish, detailed
silhouette review and per-variant hitbox tuning remain on the art QA checklist.
